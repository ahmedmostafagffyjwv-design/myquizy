# خطة بناء منصة "اختبرني" - مولّد الامتحانات الذكي

## نظرة عامة

منصة عربية (RTL) تتيح للمستخدم رفع مصدر تعليمي (PDF / DOCX / نص / صور)، ثم يولّد الذكاء الاصطناعي امتحانات مخصصة مبنية **حصريًا** على محتوى المصدر، مع إمكانية جلب صور توضيحية من الويب.

## التقنيات المستخدمة

- **TanStack Start + React + Tailwind** (الموجود حاليًا)
- **Lovable Cloud** للحسابات والتخزين وقاعدة البيانات
- **Lovable AI Gateway** (Gemini 2.5) لتوليد الأسئلة وOCR للصور
- **Firecrawl Connector** للبحث عن صور توضيحية على الويب
- **pdfjs-dist / mammoth** لاستخراج النصوص من PDF و DOCX

## هيكل الصفحات

```
/                       صفحة الهبوط (ميزات + CTA)
/auth                   تسجيل دخول/إنشاء حساب (Email + Google)
/_authenticated/
  dashboard             لوحة التحكم (إحصائيات + اختصارات)
  exams/new             رفع المصدر وإعداد الامتحان
  exams/$id             خوض الامتحان (مؤقّت + تنقّل)
  exams/$id/results     النتيجة والشرح
  exams/history         سجلّ الامتحانات السابقة
  weak-bank             بنك الأخطاء وإعادة التدريب
  stats                 إحصائيات الأداء التفصيلية
  settings              إعدادات الحساب والوضع الليلي
```

## تدفق المستخدم الأساسي

1. **رفع المصدر**: يختار المستخدم ملف (PDF/DOCX/TXT/صورة). الصور تمر بـOCR عبر Gemini Vision، PDF يُستخرج نصه في المتصفح.
2. **إعداد الامتحان**: مدة (دقائق) + عدد الأسئلة + الصعوبة (سهل/متوسط/صعب/مختلط) + النوع (MCQ/مقالي/مزيج).
3. **توليد الأسئلة**: استدعاء `createServerFn` يرسل النص + المعايير لـGemini مع نظام صارم (Structured Output) يلزم:
   - كل سؤال مرتبط بالمحتوى فقط
   - إرجاع `source_excerpt` (الجزء المرجعي من النص)
   - تحديد ما إذا كان السؤال يحتاج صورة (`needs_image: true` + `image_query`)
4. **جلب الصور**: للأسئلة التي تحتاج صورة → بحث Firecrawl Images ثم ربط أول نتيجة مناسبة.
5. **خوض الامتحان**: واجهة بمؤقت تنازلي، تنقل بين الأسئلة، حفظ تلقائي.
6. **التصحيح**: MCQ تلقائي، المقالي يُصحَّح بـAI مع درجة من 10 وملاحظات.
7. **حفظ الأخطاء**: الأسئلة الخاطئة تُضاف لـ`weak_questions` تلقائيًا.
8. **إعادة التدريب**: يمكن توليد امتحان جديد من بنك الأخطاء فقط.

## قاعدة البيانات (Lovable Cloud)

- `profiles` — معلومات المستخدم
- `sources` — المصادر المرفوعة (نص مستخرج + metadata)
- `exams` — إعدادات وحالة كل امتحان
- `questions` — الأسئلة المولّدة (نوع، صعوبة، خيارات، إجابة، مرجع، صورة)
- `attempts` — محاولات المستخدم + إجاباته + درجاته
- `weak_questions` — بنك الأخطاء مع عدّاد محاولات وتحسّن
- جميع الجداول بـRLS مرتبطة بـ`auth.uid()`

## التصميم (UI/UX)

- **اللغة**: عربية كاملة RTL (`dir="rtl"`, `lang="ar"`)
- **الخطوط**: IBM Plex Sans Arabic (عناوين) + Cairo (نص)
- **الأسلوب**: Modern Minimal على طريقة Notion/Linear مع لمسة Duolingo (ألوان مشجّعة + رسوم micro)
- **Dark/Light Mode** مع تبديل في الشريط العلوي (يحفَظ في localStorage)
- **الألوان**: قاعدة هادئة + لون أساسي (أخضر زيتي أو بنفسجي عميق) مع accent للنجاح/الخطأ
- **مكونات**: بطاقات بحواف ناعمة، حركات framer-motion للانتقالات، skeleton loaders، toast notifications
- **شريط جانبي** للوحة التحكم مع أيقونات Lucide

## الميزات الإضافية المضمَّنة

- تصدير الامتحان والنتيجة PDF (jsPDF)
- وضعان: "اختبار سريع" (5 أسئلة) و"اختبار كامل" (مخصّص)
- مخططات الأداء عبر Recharts (تطور النتائج، نسبة الصعوبات، التحسن في بنك الأخطاء)
- حفظ تلقائي للإجابات أثناء الامتحان

## ضمانات منع الهلوسة

- System prompt صارم يمنع AI من إدخال أي معلومة خارج النص
- Structured output (JSON Schema) يفرض حقل `source_excerpt` لكل سؤال
- في واجهة الامتحان: زر "عرض المرجع" يظهر المقطع من المصدر
- إن لم يجد AI ما يكفي من محتوى → يُرجع عددًا أقل من الأسئلة مع تنبيه

## تفاصيل تقنية

- استخراج PDF في المتصفح بـ`pdfjs-dist` لتفادي رفع الملف للسيرفر
- DOCX عبر `mammoth`
- صور OCR: ترفع base64 إلى Gemini Vision ضمن server function
- البحث عن صور: Firecrawl `search` مع `formats: ['links']` + فلترة الصور
- مفاتيح: `LOVABLE_API_KEY` (تلقائي) + `FIRECRAWL_API_KEY` (عبر connector)
- التخزين: bucket خاص للمصادر (private + RLS)
