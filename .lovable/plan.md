# خطة العمل

الطلب ضخم جداً (إصلاحات + إعادة هيكلة + ميزات جديدة كبيرة). سأقسّمه إلى **مرحلتين** حتى نضمن الجودة والاستقرار بدل تنفيذ كل شيء دفعة واحدة وكسر الموقع.

---

## المرحلة 1 — إصلاح المشكلات الحرجة (هذه الجلسة)

تركّز على المشكلات الثلاث المعطّلة فعلياً + صفحة "عن المشروع".

### 1) إصلاح تأخّر ظهور النتيجة بعد التسليم
- المشكلة الجذرية: `submitAll` يستدعي `save` و `finish` بدون إبطال (invalidate) للـ React Query cache، فصفحة النتائج تعرض بيانات قديمة حتى التحديث اليدوي.
- الحل:
  - استخدام `useMutation` مع `onSuccess` لإبطال `["exam-results", id]` و `["exam", id]` و `["weak-bank"]` و `["dashboard-stats"]` قبل التنقّل.
  - `await queryClient.invalidateQueries(...)` قبل `navigate`.
  - شاشة تحميل احترافية أثناء التصحيح (`ResultLoadingScreen` بـ skeleton + رسالة "جارٍ تصحيح إجاباتك...").
  - معالجة أخطاء الشبكة مع زر إعادة المحاولة.
  - تشغيل عمليات الحفظ بالتوازي عبر `Promise.all` بدل التسلسل (أسرع بكثير لامتحان فيه 10 أسئلة).

### 2) إصلاح "الامتحان المجمّع للأخطاء" في `weak-bank`
- المشكلة: عند توليد امتحان من بنك الأخطاء، الأسئلة تُولَّد من جديد بالـ AI بدل استخدام الأسئلة الخاطئة الفعلية المحفوظة.
- الحل:
  - زر جديد "امتحنّي على كل أخطائي" يستخدم الأسئلة الموجودة في `weak_questions` مباشرة (بدون AI) — نسخها لامتحان جديد.
  - منع التكرار: `SELECT DISTINCT ON (question_id)` + ترتيب حسب `times_wrong DESC`.
  - الإبقاء على زر "إعادة تدريب من نفس المصدر" الحالي كخيار ثانوي.
  - عند الانتهاء، تحديث `weak_questions` (mastered/times_correct) تتم تلقائياً عبر `saveAttempt` الحالي ✓.

### 3) إصلاح مراجعة أخطاء كل اختبار على حدة
- صفحة النتائج `exams.$id.results.tsx` تعرض كل الأسئلة بالفعل، لكن ينقصها:
  - زر "أعد اختبار الأخطاء فقط" — ينشئ امتحاناً جديداً من الأسئلة الخاطئة لهذا الاختبار تحديداً (بنفس آلية النقطة 2 لكن مفلتر بـ `exam_id`).
  - تحسين قسم المراجعة: عرض أوضح للسؤال/إجابتك/الصحيحة/الشرح (موجود لكن يحتاج تحسين بصري).

### 4) صفحة "عن المشروع"
- مسار جديد `/about` (عام، غير محمي) بالنص المطلوب عن أحمد مصطفى.
- رابط في الـ AppShell والصفحة الرئيسية + ميتاداتا SEO.

### تفاصيل تقنية
- ملفات معدّلة: `src/routes/_authenticated/exams.$id.tsx`, `exams.$id.results.tsx`, `weak-bank.tsx`, `src/lib/attempts.functions.ts` (إضافة `generateExamFromWeak`), `src/components/app-shell.tsx`.
- ملف جديد: `src/routes/about.tsx`.
- لا تغييرات على schema قاعدة البيانات في هذه المرحلة (الجداول الحالية كافية).
- تحقّق يدوي بعد كل إصلاح عبر الـ preview.

## المرحلة 2 — الميزات الكبرى (جلسات لاحقة)

هذه ميزات ضخمة، كل واحدة منها تحتاج جلسة منفصلة:

- **نظام المواد والمجلدات الهرمي**: جدول `folders` بعلاقة `parent_id`، ربط `sources` بـ `folder_id`، واجهة شجرة، رفع متعدد.
- **اختبار حسب الفصل بأمر طبيعي** ("اختبرني على الفصل الأول"): يحتاج المجلدات أولاً + معالج أوامر AI.
- **لوحة إحصائيات متقدمة**: رسوم بيانية، تتبّع أسبوعي، أكثر المواضيع خطأً.
- **نظام التكرار الذكي (Spaced Repetition)** و**كشف الأسئلة المتكرّرة** (يحتاج embeddings).
- **بحث ذكي شامل** و**تصدير/استيراد** قاعدة البيانات.

سأنفّذها بعد اعتماد المرحلة 1 وبترتيب الأولوية الذي تختاره.
